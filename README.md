📊 Sales and Revenue Performance Analysis
An interactive Sales & Revenue Performance Analysis Dashboard built using Python, Streamlit, Pandas, Plotly, and Machine Learning to analyze business performance, customer behavior, and sales forecasting.

🎓 Academic Collaborative Project

Developed by: Mohammad Faizan, Akash Kumar, Ashish Bera, and Aviral Rastogi

📌 Project Overview
Sales and Revenue Performance Analysis is an interactive business intelligence dashboard that enables users to analyze sales performance, revenue trends, customer purchasing behavior, and future sales predictions.

The project combines Data Analytics, Business Intelligence, and Machine Learning to transform raw retail transaction data into meaningful business insights through interactive visualizations and predictive analytics.

✨ Key Features
📊 Interactive Business Dashboard
📈 Sales Performance Analysis
💰 Revenue Analysis
🌍 Country-wise Sales Insights
📅 Monthly & Daily Sales Trends
👥 Customer Segmentation using RFM Analysis
🤖 Customer Clustering using K-Means
🔮 Sales Forecasting using Machine Learning
📉 Business KPIs & Insights

🚀 Installation Guide
Clone the Repository
git clone https://github.com/ashish6060/Sales-and-Revenue-Performance-Analysis.git
Navigate to the Project Folder
cd Sales-and-Revenue-Performance-Analysis
Install Required Libraries
pip install -r requirements.txt
Run the Streamlit Application
streamlit run app.py
